# Anylog Setup

contains the docker-compose setup files for anylog

.env file is the local environment variables for starting up anylog

**Docker-compose-files**

The docker-compose-files folder contains the anylog master and operator node .yaml startup files

**Config Folders**

-> master-configs:
contains the advance and base config .env files for the anylog master node which the operator connects to

-> operator-configs
contains the advance and base config .env files for the anylog operator node which is the main node for data collection and querying
